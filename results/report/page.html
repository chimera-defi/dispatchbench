Which model should a coding task go to?

🏆 WINNER Build with luna-high, let haiku-low repair a failed check, and use sonnet-medium when no miss is acceptable.
  • Cheapest safe single model: haiku-low, 95% at $0.00112 per pass. luna-high: 92% at $0.00105.
  • A Haiku repair took luna-low from 21/35 to 35/35 on its hardest problems. sonnet-medium passed 75/75.

❓ How it was run

  • L1 overlap_minutes: minutes with at least k meetings at once; half-open intervals, sweep line
  • L1 squash: run-length encoding with escaped digits and backslashes
  • L2 ledger: bank operations with validation rules, frozen accounts and transfers
  • L2 taller_within: count taller people among the k in front; sliding window
  • L3 pass_route: cheapest route when zone passes can be bought on the way; state-space shortest path
  • L3 calc: integer expression parser: precedence, right-assoc power, unary minus, errors
  • L4 weighted_distance_sums: weighted distance sums from every tree node; rerooting
  • L4 recur: calendar recurrence rules (daily, weekly, monthly) expanded to dates
  • L5 k_machine_schedule: best total pay for jobs on k printers; weighted interval scheduling
  • L5 avoid_count: count strings avoiding banned substrings; automaton DP, modulo
  • L6 best_average: largest average of a subarray of length at least k, as an exact fraction
  • L6 sheet: spreadsheet evaluator with references, ranges, division and cycle errors
  • L7 xor_ring: XOR cellular automaton on a ring for huge t; doubling
  • L7 bounce_board: expected turns on a bouncing board game with jumps, as an exact fraction
  • L7 paint_erase: paint and erase ranges where higher colours win; segment tree
  • 5 attempts per problem per config, tools off; L7 ran later on haiku-low, sonnet-medium, sol61-medium and luna-high.
  • Pass = every hidden test passes: fixed cases, random small cases checked against a brute force, and big cases for speed. Planted wrong answers must fail.
  • Claude $ is measured by the CLI; Codex $ is tokens × list price.
  • Intervals: hierarchical bootstrap over problems, 10,000 resamples.
  • Repo tasks: 4 tasks × 3 attempts, hidden tests; all 48 runs passed.

💡 What to do

  1. Build: luna at high effort.
  2. Failed check: haiku-low repairs, claude -p --tools "".
  3. No miss acceptable, or the hardest problems: sonnet-medium.
  4. Never luna at low or medium effort.
⚠️ Caveats
  • Small sample: read the intervals before the point estimates.
  • luna-high was added after the main run (exploratory).
  • Codex cost swings up to 2.6× with prompt-cache hits.
  • Latency is CLI wall clock, up to 4 calls in flight on one host.
  • One run in time; hosted models change.

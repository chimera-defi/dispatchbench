❓ How it was run

📚 Problems by round (Easy/Medium/Hard)
  • Pilot: well-known LeetCode problems. Every config passed, so it ranked nothing and is not scored.
    • Easy Fizz Buzz
    • Medium Course Schedule II
    • Hard Candy
    • Hard Reconstruct Itinerary
    • Hard Minimum Window Substring
    • Hard Wildcard Matching
  • Round 1: 12 new problems on rungs L1–L6, every config.
    • Medium L1 overlap_minutes: minutes with at least k meetings at once; half-open intervals, sweep line
    • Easy L1 squash: run-length encoding with escaped digits and backslashes
    • Medium L2 ledger: bank operations with validation rules, frozen accounts and transfers
    • Medium L2 taller_within: count taller people among the k in front; sliding window
    • Medium L3 pass_route: cheapest route when zone passes can be bought on the way; state-space shortest path
    • Hard L3 calc: integer expression parser: precedence, right-assoc power, unary minus, errors
    • Hard L4 weighted_distance_sums: weighted distance sums from every tree node; rerooting
    • Medium L4 recur: calendar recurrence rules (daily, weekly, monthly) expanded to dates
    • Hard L5 k_machine_schedule: best total pay for jobs on k printers; weighted interval scheduling
    • Hard L5 avoid_count: count strings avoiding banned substrings; automaton DP, modulo
    • Hard L6 best_average: largest average of a subarray of length at least k, as an exact fraction
    • Hard L6 sheet: spreadsheet evaluator with references, ranges, division and cycle errors
  • Round 2: 3 harder problems on rung L7, run later on haiku-low, sonnet-medium, sol61-medium, luna-high.
    • Hard L7 xor_ring: XOR cellular automaton on a ring for huge t; doubling
    • Hard L7 bounce_board: expected turns on a bouncing board game with jumps, as an exact fraction
    • Hard L7 paint_erase: paint and erase ranges where higher colours win; segment tree
  • Each config tries each problem 5 times, tools off.
  • Pass = every hidden test passes (fixed, random vs the reference solution, large for speed).
  • Sample tests = the worked examples in the problem text. Cheap to run, and the model can see them.
  • Claude $ from the CLI. Codex $ = tokens × list price (marked ~). Intervals: bootstrap, 10,000 resamples.
  • Run by a Claude Opus 5.5 orchestrator. It is not one of the configs tested.
Exact commands
  • claude -p --model claude-haiku-5-5 --effort low|medium --output-format json --no-session-persistence --tools "" --setting-sources "" --strict-mcp-config
  • claude -p --model claude-sonnet-5-5 --effort medium --output-format json --no-session-persistence --tools "" --setting-sources "" --strict-mcp-config
  • codex exec -m gpt-6-luna -c model_reasoning_effort=low|medium|high --ignore-user-config -c skills.include_instructions=false -c service_tier=default --json --ephemeral --skip-git-repo-check -s read-only
  • codex exec -m gpt-6.1-sol -c model_reasoning_effort=medium --ignore-user-config -c skills.include_instructions=false -c service_tier=default --json --ephemeral --skip-git-repo-check -s read-only
  • luna-low-bare and luna-high-bare add the stripped harness from bench/trim_probe.py. Every luna-high row on the hard set uses it.

  • avoid: passes under 90%.

Hard set: passes, $ per pass, median seconds

35 attempts on 7 problems chosen after round 1 (luna-low fails them most). Single models: their main-run attempts. Purple = luna builds, then Haiku reviews and fixes: H all = every answer; H fail = only when sample tests fail.

  • ✅ Haiku fixing every luna-high-bare answer: 35/35. But haiku-medium alone also had 0 misses, 1.8× cheaper.
  • ⚠️ Sample tests are a weak gate: they caught 2 bad luna-high answers and missed 3. luna-low fails them more often (13 repairs), so the gate helps it more.
  • ❌ A Haiku plan before luna helped less: luna-low 30/35, luna-high 31/35 (alone: 31/35). Check after, don't plan first.
✅ CONCLUSION One model is enough: haiku-medium.
  1. Default: haiku-medium (claude -p --tools "").
  2. Tight budget: haiku-low.
  3. Zero misses needed, or the hardest problems: sonnet-medium.
  4. Best luna + Haiku pipeline: also 0 misses, but 1.8× the cost of haiku-medium alone.
  5. Never luna-low or luna-medium alone.

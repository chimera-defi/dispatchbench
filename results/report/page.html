✅ CONCLUSION

Four configs passed every try in every set (repo tasks counted as task complete, hidden and visible tests both pass): haiku-high, sonnet-medium, sol61-high and astra-medium. haiku-high is the cheapest, at $0.0028 per pass.
  1. With Codex quota left, send each task to sol61-high ⚡.
  2. Then run the sample tests. If one fails, haiku-low fixes it. Tested with plain sol61-high: 35/35 on the retest set, one run; sample tests are a weak gate. Haiku never ran.
  3. With Codex quota gone, use haiku-high. It is the cheapest config with no misses.
  • If speed matters most, use sonnet-medium. It takes 10.1 s to haiku-high's 14.7 s. sonnet-medium costs 4.4× as much per pass.
  • Don't use luna-low or luna-medium alone: they miss about 1 answer in 4.
  • luna-low passed 11 more on Codex's bench; haiku-low gained 3, near its ceiling. Bench and harness both differ, so the cause is not isolated. No pick changes.

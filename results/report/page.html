🏆 WINNER

Use sol61-high when Codex has quota. Use haiku-high when it does not, or when you need speed.

Four test sets: main ladder (12 new problems × 5 tries = 60), L7 (3 extra-hard problems × 5 = 15), rescue (the 7 ladder problems luna missed most × 5 = 35), repo tasks (4 real-repo edits with tools × 3 = 12).

  1. Codex has quota? sol61-high at normal speed (not fast mode). After it answers, run the problem's worked examples. If any fail, haiku-low fixes the answer. In this run no fix was ever needed. $0 on the Claude bill.
  2. Codex out? haiku-low ($0.00112 per pass, 57/60); haiku-high when a miss is costly (never missed, $0.0028 per pass).
  3. Need it faster than sol61-high's 27.4 s? haiku-high: 14.7 s, never missed, $0.0028 per pass on the Claude bill. Must stay on Codex? sol61-high fast: 17.4 s, $0.0359 per pass, about 1.9× more Codex usage than sol61-high. astra-medium fast (9.9 s, $0.1520 per pass) is the fastest-at-any-price choice.

Why:

  • ✅ haiku-medium: 59/60 on the main ladder, zero misses on the rescue set. $0.00149 per pass, 13.0s. Measured $, not estimated.
  • 💸 haiku-low: 57/60 on the main ladder at $0.00112. Misses: too slow or a crash, never a wrong answer.
  • 🐢 The Codex picks are slow on repo tasks: 109s and 85s median against about 28s for a Claude builder.
  • Fast mode (Codex's priority tier, about 2× the price) cuts sol61-high to 17.4 s and astra-medium to 9.9 s, both still zero misses. Chart: Results, "Codex fast mode".

❓ How it was run

Every config faced the same new problems and hidden tests, with tools off (the model could not run code, read files or search). 12 problems × 5 attempts = 60 calls per config; total spend: $2.46 Claude, $35.40 Codex (estimated from tokens).

  • Claude $ from the CLI. Codex $ = tokens × list price; ~ means estimated from tokens, not billed. 95% intervals from 10,000 bootstrap resamples (how much the pass rate would wobble on a rerun).

✅ CONCLUSION

Use sol61-high when Codex has quota. Use haiku-high when it does not, or when you need speed.
  1. Codex has quota: sol61-high. Run the worked examples after; haiku-low fixes only if they fail ($0 Claude).
  2. Need it faster than sol61-high's 27.4 s? haiku-high: 14.7 s, never missed, $0.0028 per pass on the Claude bill. Must stay on Codex? sol61-high fast: 17.4 s, $0.0359 per pass, about 1.9× more Codex usage than sol61-high. astra-medium fast (9.9 s, $0.1520 per pass) is the fastest-at-any-price choice.
  3. Claude only (Codex out): haiku-low (claude -p --tools ""); haiku-high on a failed check or when a miss is costly.
  4. Want a bigger Claude model with zero misses? sonnet-medium, at 8× haiku-medium's cost.
  5. Best luna + Haiku pipeline: luna-high-bare → Haiku reviews every answer; passed 35/35, but cost 1.8× as much as haiku-medium alone.
  6. Never luna-low or luna-medium alone.

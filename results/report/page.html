Codex $

❓ How it was run

Every config (model + effort) got the same new problems and hidden tests. Tools were off: no code runs, file reads or search. Logs confirm it for 938 of 938 Codex calls.

📐 How to read this data: sets, tests, prices, intervals
  • Planted wrong answers must fail the hidden tests. Sample tests = the worked examples the model sees.
  • Cost totals leave out the pilot, runner (harness) bias, trim and retest set pipeline runs.
  • Sets:
    • main ladder has 12 problems. Each gets 5 tries. Total: 60 calls.
    • L7 set has 3 problems. Each gets 5 tries. Total: 15 calls.
    • Retest set covers the 7 main-ladder problems. They are the ones that luna-low, luna-medium or luna-low-bare missed. They were chosen after the main run. Each config made 35 calls.

  • Hidden tests: fixed cases, random cases checked against a reference, and large cases for speed.
  • Claude $: what the CLI reports.
  • The 95% range uses 10,000 bootstrap resamples. It shows how much a rerun's pass rate can vary.

✅ CONCLUSION

Four configs passed every try in every set: haiku-high, sonnet-medium, sol61-high and astra-medium. haiku-high is the cheapest, at $0.0028 per pass.
  1. With Codex quota left, send each task to sol61-high ⚡.
  2. Then run the sample tests. If one fails, haiku-low fixes it. Tested with plain sol61-high: 35/35 on the retest set. Haiku never ran.
  3. With Codex quota gone, use haiku-high. It is the cheapest config with no misses.
  • If speed matters most, use sonnet-medium. It takes 10.1 s to haiku-high's 14.7 s. sonnet-medium costs 4.4× as much per pass.
  • Don't use luna-low or luna-medium alone: they miss about 1 answer in 4.
  • Codex CLI lifted luna-low by 11 passes. haiku-low gained 3, near its ceiling. No pick changes.

⚠️ Limitations

A routing signal from a small, self-written set, not a general ranking. Read the intervals first.

What could mislead
  • Scope: 12 main problems, written for this bench.
  • Most have a LeetCode analogue, and LeetCode code is widely public.
  • The problems ship with this repo, so later models can read them.
  • The 95% range resamples whole problems, since tries on the same problem are related.
  • L7 has 3 problems. Perfect score: 15/15. That only shows a pass rate of at least 37%.
  • Every repo task passed, so they rank cost and speed, not skill.
  • Paired gaps of 3 points or less did not separate; 18-point gaps did.
  • PLAN.md was committed before the main run; a same-day pilot came first.
  • 10 configs were added after seeing the main-run results (†). These include the haiku-high and sol61-high picks:
    • astra-medium

  • A Codex call's estimated $ drops up to 5.8× when the prompt cache hits.
